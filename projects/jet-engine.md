## What was the project brief?

To analyse the performance of a SR-30 turbo-jet engine. As part of the project, I was provided with data which was recorded from the engine during normal operation by the module lecturer which I conducted the analysis on. 

Following this analysis, presenting the findings in a structured scientific report which included several thermodynamic performance metrics. 

Finally, a conclusion from all of the results and a short reflective piece on the project as part of my continued professional development. 

## What was my approach?

In the project specification, there were several values/performance graphs listed which needed to be calculated and then presented as part of the final report. I used MATLAB to complete the calculations as this allowed me to implement them in code and allow for values which changed throughout the run, such as the specific heat capacity Cp.

## Outcomes - How successful was the project?

I was able to complete all of the tasks outlined in the project brief, and completed a thorough analysis of the dataset that I'd been provided with. I felt that the project was successful overall.
